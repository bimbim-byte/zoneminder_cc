Sumber Data Kamera
Paste daftar URL, atau unggah berkas Excel dengan kolom Zone.
Hanya sheet pertama yang dibaca. Baris pertama wajib berisi nama kolom.
Kolom wajib hanya dua: Name dan Source Path. Kolom lain boleh dihilangkan atau dikosongkan — nilainya diambil dari panel Pengaturan Default di bawah. Urutan kolom bebas; yang menentukan adalah nama header-nya, bukan posisinya.
Nama Kolom Wajib Isi & Nilai yang Diterima Bila Dikosongkan
Name Ya Nama kamera di ZoneMinder. Huruf, angka, garis bawah, dan tanda hubung. Karakter lain otomatis diubah menjadi _.
Contoh: CAM_LOBBY_01
 Diisi otomatis CCTV_<nomor>
Source Path Ya URL RTSP lengkap kamera, wajib diawali rtsp://. Baris tanpa ini ditolak saat pendaftaran.
Contoh: rtsp://admin:pass@192.168.1.10:554/ch1
Header lain yang diterima: Path
 Baris dilewati dengan status gagal
Function Tidak Mode kerja kamera: Monitor, Modect, Record, Mocord, atau Nodect.
Monitor = siaran langsung saja, tanpa rekam. Modect = rekam saat ada gerakan (butuh zone). Record = rekam terus-menerus.
Ikut Pengaturan Default
Width
Height		 Tidak Resolusi kamera dalam piksel, angka saja tanpa satuan. Harus sesuai resolusi asli stream — bila salah, gambar gepeng dan zone deteksi tidak menutupi seluruh bidang pandang.
Contoh: 1920 dan 1080
 1920 × 1080
Max FPS Tidak Batas frame per detik. Kosong atau 0 berarti mengikuti FPS asli kamera. Angka besar membebani CPU server.
Saran: 15 untuk pemantauan biasa
 Tidak dibatasi
Zone Tidak Mode zone deteksi untuk kamera ini. Menerima angka 1–5 atau nama mode (lihat tabel di bawah). Nilai di sini mengalahkan mode global.
Header lain yang diterima: Zone Mode, Mode Zone, zone
Ikut Mode Zone Global
Type Tidak Tipe sumber di ZoneMinder. Untuk kamera IP biarkan Ffmpeg; hampir tidak pernah perlu diubah. Ffmpeg
Nilai kolom Zone yang diterima
Angka kecil = lebih sensitif dan lebih berat di CPU; angka besar = lebih hemat CPU tetapi hanya gerakan besar yang memicu alarm. Tanpa zone, kamera berfungsi Modect tetap tidak akan pernah menghasilkan alarm.

Baris ketiga sengaja mengosongkan Zone: kamera itu memakai mode dari panel Pengaturan Default. Function Record juga tidak butuh zone karena merekam terus-menerus, bukan menunggu gerakan.
Yang sering membuat gagal:
  • Nama header tidak sama persis, mis. SourcePath atau Nama — spasi dan huruf besar-kecil berpengaruh.
  • URL RTSP diapit tanda kutip oleh Excel sehingga terbaca "rtsp://..." — hapus tanda kutipnya.
  • Resolusi ditulis 1920x1080 dalam satu sel — harus dua kolom terpisah berisi angka.
  • Berkas masih terbuka di Excel saat diunggah — tutup dulu agar versi terbaru yang terbaca.
Nilai Zone yang tidak dikenali tidak membuat unggahan gagal; nilainya diabaikan dan kamera memakai mode global. Setelah unggah, daftar nilai yang tidak dikenali ditampilkan agar bisa diperbaiki.
