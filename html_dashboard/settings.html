🌐 Kredensial ZoneMinder

Username dan password ZoneMinder disimpan terenkripsi (AES-256-GCM) di data/zm_credentials.enc dengan kunci dari DASH_SECRET_KEY. Setelah disimpan, dashboard memakai nilai ini — tidak perlu mengedit kode atau .env lagi saat password ZM berganti.

Urutan yang benar saat mengganti password ZoneMinder:
  1. Ganti password di ZoneMinder lebih dulu (UI: Options → Users, atau SQL).
  2. Uji kredensial baru dengan tombol Test Connection di atas.
  3. Klik Simpan Kredensial.
  4. Untuk service checker, jalankan docker compose up -d agar ZM_USER/ZM_PASS di .env ikut diperbarui.
Jika Anda menyimpan kredensial yang salah, dashboard akan gagal memuat daftar kamera. Uji dulu dengan Test Connection untuk menghindari kondisi itu.
