📘 2. Panduan Integrasi: Pasang Notifikasi MQTT di HP Android / iOS & Device Lain ▲ Tutup Panduan

Terima peringatan instan ketika kamera CCTV mati/terputus langsung ke ponsel Android, iPhone, tablet, atau sistem lain (Home Assistant, Telegram Bot, Node-RED, ESP32) menggunakan broker Mosquitto MQTT yang sudah aktif.

1. Parameter Koneksi Broker Mosquitto MQTT

Parameter Nilai / Konfigurasi Keterangan Penggunaan
Broker Host / IP 192.168.x.x atau localhost Gunakan IP LAN komputer server untuk diakses dari HP/Device lain dalam satu jaringan WiFi.
Port TCP (Native MQTT) 1883 Wajib untuk: Aplikasi HP (MQTT Dash / IoT MQTT Panel), Home Assistant, Python, ESP32.
Port WebSocket (WSS) 9001 / 443 (/mqtt) Digunakan khusus untuk browser web atau aplikasi web client.
Autentikasi Anonymous (Tanpa User & Password) Kosongkan kolom username dan password di aplikasi penerima.
Topik Notifikasi (Event) cctv/events (Sangat Direkomendasikan) Mengirim sinyal saat status kamera beralih ONLINE / OFFLINE.
Topik Ringkasan (Summary) cctv/summary Mengirim data total kamera, total online, dan total offline secara periodik.
Topik Wildcard (Semua) cctv/# Menerima seluruh pesan dari semua saluran CCTV.
Topik Trigger Remote cctv/control/run_now Kirim pesan kosong ke topik ini dari HP untuk memicu cek kamera jarak jauh.

3. Cara Pasang di Aplikasi HP Android / iOS (Contoh: MQTT Dash)

Langkah 1: Unduh Aplikasi MQTT Client

Buka Google Play Store (Android) atau App Store (iOS), lalu instal aplikasi gratis seperti MQTT Dash, IoT MQTT Panel, atau MQTT Tool.

Langkah 2: Tambahkan Koneksi Broker Baru

- Name: ZoneMinder CCTV Alert
- Address / Host: Masukkan IP Server lokal komputer ini (Contoh: 192.168.1.50)
- Port: 1883
- Client ID: Bebas / Acak
- Simpan (Save) dan pastikan ikon koneksi berubah menjadi hijau (Connected).

Langkah 3: Buat Tile / Notifikasi Alarm

- Tambahkan widget baru bertipe Text / Log atau Multi-State.
- Masukkan Topic: cctv/events
- Aktifkan fitur "Enable notifications on receive" atau "Alert on OFFLINE".
- Sekarang, setiap kali koneksi kamera CCTV mati atau hidup kembali, HP Anda akan bergetar dan memunculkan pop-up notifikasi!

4. Script Contoh Python Listener untuk PC / Laptop Lain

import paho.mqtt.client as mqtt import json BROKER = "192.168.1.50" # Ganti dengan IP komputer server ZoneMinder Anda PORT = 1883 def on_message(client, userdata, msg): try: data = json.loads(msg.payload.decode()) print(f"[{data.get('timestamp')}] {data.get('status')}: {data.get('message')}") except Exception: print(f"[{msg.topic}] {msg.payload.decode()}") client = mqtt.Client() client.on_message = on_message client.connect(BROKER, PORT, 60) client.subscribe("cctv/events") print("[*] Mendengarkan notifikasi ZoneMinder CCTV... Tekan Ctrl+C untuk berhenti.") client.loop_forever()
