📘 Panduan Integrasi: Pasang Notifikasi CCTV MQTT di HP Android / iOS & Device Lain

Terima notifikasi popup dan nada dering seketika saat ada kamera CCTV yang mati atau kembali online menggunakan broker Mosquitto MQTT:

1. Parameter Koneksi Broker Mosquitto MQTT

Parameter Nilai / Konfigurasi Keterangan
Broker Host <IP_SERVER> (IP Komputer Server) Gunakan IP LAN komputer server untuk diakses dari HP / device lain di satu WiFi.
Port TCP (Native MQTT) 1883 Wajib untuk: Aplikasi HP (MQTT Dash / IoT MQTT Panel), Home Assistant, Python, ESP32.
Port WebSocket (WSS) 9001 atau 443 (/mqtt) Khusus aplikasi web / browser client.
Autentikasi Anonymous (Tanpa User & Password) Kosongkan kolom username dan password di aplikasi penerima.
Topik Notifikasi Utama cctv/events (Sangat Direkomendasikan) Mengirim sinyal saat status kamera beralih ONLINE / OFFLINE.
Topik Status Spesifik cctv/status/+ Status individual per kamera (contoh: cctv/status/kamera_depan).
Topik Ringkasan (Summary) cctv/summary Data berkala total kamera online & offline.
Topik Trigger Remote cctv/control/run_now Publish pesan kosong ke topik ini dari HP untuk memicu cek kamera saat itu juga.

2. Contoh Struktur Payload JSON (Topic: cctv/events)

{ "timestamp": "2026-11-05 10:15:00", "monitor_id": "2", "name": "Kamera_Gerbang_Utama", "status": "OFFLINE", "rtsp_url": "rtsp://admin:pass@192.168.1.100:554/stream1", "message": "Kamera 'Kamera_Gerbang_Utama' TERPUTUS (OFFLINE)" }

3. Cara Pasang di Aplikasi HP Android / iOS (Contoh: MQTT Dash)

Langkah 1: Unduh Aplikasi MQTT Client

Buka Google Play Store atau Apple App Store, lalu instal MQTT Dash atau IoT MQTT Panel.

Langkah 2: Tambahkan Koneksi Broker Baru

- Name: ZoneMinder CCTV Alert
- Address / Host: Masukkan IP LAN Komputer Server ini (Contoh: 192.168.1.50)
- Port: 1883 • Client ID: Bebas / Acak
- Simpan (Save) dan pastikan ikon berubah hijau (Connected).

Langkah 3: Buat Tile / Notifikasi Alarm

- Tambahkan widget baru bertipe Text / Log.
- Masukkan Topic: cctv/events
- Aktifkan fitur "Enable notifications on receive".
- HP Anda kini akan bergetar dan membunyikan alarm setiap kali koneksi CCTV mati atau pulih kembali!

4. Script Contoh Python Listener untuk PC / Laptop Lain

import paho.mqtt.client as mqtt import json BROKER = "192.168.1.50" # Ganti dengan IP komputer server ZoneMinder Anda PORT = 1883 def on_message(client, userdata, msg): try: data = json.loads(msg.payload.decode()) print(f"[{data.get('timestamp')}] {data.get('status')}: {data.get('message')}") except Exception: print(f"[{msg.topic}] {msg.payload.decode()}") client = mqtt.Client() client.on_message = on_message client.connect(BROKER, PORT, 60) client.subscribe("cctv/events") print("[*] Mendengarkan notifikasi ZoneMinder CCTV... Tekan Ctrl+C untuk berhenti.") client.loop_forever()
